# Mega Crypto Terminal 3000
**Mega Crypto Terminal 3000** - это веб-приложение для выполнения криптографических операций. Проект выполнен в рамках тестового задания и реализует следующий функционал:
- Поддержка присоединенной и отсоединенной подписи с использованием алгоритма RSA
- Шифрование и дешифрование RSA + AES (AES GCM для данных, RSA для обертки ключа)
- Расчет хеша алгоритмом SHA-256
- Загрузка ресурсов

Приложение доступно по адресу `https://alfa.cr4.sh`

## Запуск 
1.  Клонируйте репозиторий

    ```bash
    git clone https://github.com/babaika404/alfa-test.git
    ```
2.  Настройте `.env`
3.  Запустите сборку

    ```bash
    docker-compose up --build
    ```
4.  По умолчанию приложение будет работать по адресу `http://localhost:10001`

*При первом запуске `entrypoint.sh` автоматически сгенерирует ключи, если они отсутствуют.*


## Настройка

Параметры приложения управляются через файл `.env`

| Переменная | Описание |
| :--- | :--- |
| `APP_PORT` | порт приложения |
| `APP_KS_PSWD` | пароль к keystore (PKCS12) |
| `APP_KS_ALIAS` | имя ключа в keystore |
| `APP_KS_PATH` | путь к файлу keystore внутри контейнера |
| `APP_DOWNLOAD_HOST` | список разрешенных доменов для загрузки |
| `APP_DOWNLOAD_EXT` | список разрешенных расширений для загрузки |
